# awesome-jupyter-examples
A collection of a couple of Jupyter Notebook Examples

Currently there is a Dockerfile and a docker compose setup, that will setup a neo4j database along with graph datascience to evaluate neo4j together with a Jupyter Notebook server that has the 
[yFiles Graphs for Jupyter for Neo4j](https://github.com/yWorks/yfiles-jupyter-graphs-for-neo4j/) widget readily installed. It shows how to create nice visualizations quickly from a simple database with custom visualizations.
